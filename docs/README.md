# Calculate Pi Scripts Documentation

This guide is for readers who want to run an example, learn how its algorithm works, or build it with their own language tools. You do not need to install every language in the repository.

## Start here

- [Getting started](getting-started.md): clone the project, launch the CLI, or choose a source example.
- [Languages and commands](languages.md): where each implementation lives and how to run or compile it.
- [Algorithms](algorithms.md): a beginner-friendly overview of the methods used.
- [Toolchains](toolchains.md): runtime/compiler requirements and official installation sources.
- [Troubleshooting and FAQ](troubleshooting.md): common errors, platform limits, and answers.

The CLI supports seven languages: Python, C, C++, Rust, Go, Java, and Julia. The wider source collection also includes examples in other languages; those are not automatically added to the CLI.
